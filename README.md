## 🚀 დაყენება (ერთხელ, ~10 წუთი)

### 1. ntfy აპი iPhone-ზე
1. App Store-დან დააყენე **ntfy**.
2. მოიფიქრე გრძელი, გამოუცნობი თემის სახელი, მაგ. `aq-chaweret-sheni-tema`.
   ⚠️ ntfy.sh-ზე თემა ფაქტობრივად პაროლია: ვინც სახელი იცის, შეტყობინებებს ნახავს.
3. აპში დააჭირე **+** და გამოიწერე ეს თემა.

### 2. Travelpayouts-ის გასაღები (უფასო)
1. დარეგისტრირდი: <https://www.travelpayouts.com>
2. **Profile → API token** (ან „Developers“) → დააკოპირე token.

### 3. GitHub Secrets
რეპოზიტორიაში: **Settings → Secrets and variables → Actions → New repository secret**:

| სახელი | მნიშვნელობა |
|---|---|
| `NTFY_TOPIC` | შენი თემის სახელი (მაგ. `aq-chaweret-sheni-tema`) |
| `TRAVELPAYOUTS_TOKEN` | Travelpayouts token |

### 4. აპლიკაციის გამოქვეყნება (GitHub Pages)
1. რეპოზიტორია უნდა იყოს **Public** — მაშინ GitHub Pages და Actions სრულიად უფასოა და ულიმიტოა.
   (საიდუმლო არაფერი ინახება: ntfy თემა და token მხოლოდ Secrets-შია.)
2. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
3. პირველი გაშვების შემდეგ აპი გაიხსნება აქ: `https://<შენი-github-სახელი>.github.io/<რეპოზიტორია>/`
4. iPhone-ზე Safari-ში გახსენი → **Share → Add to Home Screen.** აპივით გაიხსნება.

### 5. გაშვება
**Actions → Check cheap flights → Run workflow.** პირველივე გაშვებაზე მოგივა მისასალმებელი შეტყობინება.
ამის შემდეგ ყველაფერი ავტომატურად მუშაობს დღეში 2-ჯერ, ~09:17 და ~21:17-ზე. GitHub ზოგჯერ აგვიანებს ან ტოვებს გაშვებას — ამიტომ 11:47-ზე და 23:47-ზე სათადარიგო შემოწმებაა, რომელიც მხოლოდ მაშინ ეშვება, თუ მთავარი არ შედგა.

## 🛠 ტექნიკური
- `flight_alerts/sources/`: Wizz Air და Travelpayouts.
- `flight_alerts/combine.py`: ერთი მიმართულების ბილეთებიდან წასვლა-დაბრუნების აწყობა.
- `flight_alerts/settings.py`: ტელეფონიდან მიღებული ბრძანებები.
- `flight_alerts/export.py`: აპის მონაცემები (`flights.json`) და ისტორია (`history.json`).
- `web/`: აპლიკაცია (HTML/CSS/JS, build არ სჭირდება). ფერები `web/style.css`-ის თავშია (`:root`).
- მონაცემები ინახება ცალკე `data` ბრანჩზე, რომელიც ყოველ ჯერზე გადაიწერება — რეპოზიტორია არ იზრდება.
- ისტორია ინახავს მხოლოდ ფასის ცვლილებებს (დღის მინიმუმს); გასული ფრენები ავტომატურად იშლება.
- კურსი: საქართველოს ეროვნული ბანკი (NBG).
- ლოკალურად გაშვება: `pip install -r requirements.txt && DRY_RUN=1 python -m flight_alerts`
- ტესტები: `pip install pytest && pytest`
