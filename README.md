## 🚀 დაყენება (ერთხელ, ~10 წუთი)

### 1. ntfy აპი iPhone-ზე
1. App Store-დან დააყენე **ntfy**.
2. მოიფიქრე გრძელი, გამოუცნობი თემის სახელი, მაგ. `luka-flights-8x3k29qz`.
   ⚠️ ntfy.sh-ზე თემა ფაქტობრივად პაროლია: ვინც სახელი იცის, შეტყობინებებს ნახავს.
3. აპში დააჭირე **+** და გამოიწერე ეს თემა.

### 2. Travelpayouts-ის გასაღები (უფასო)
1. დარეგისტრირდი: <https://www.travelpayouts.com>
2. **Profile → API token** (ან „Developers“) → დააკოპირე token.

### 3. GitHub Secrets
რეპოზიტორიაში: **Settings → Secrets and variables → Actions → New repository secret**:

| სახელი | მნიშვნელობა |
|---|---|
| `NTFY_TOPIC` | შენი თემის სახელი (მაგ. `luka-flights-8x3k29qz`) |
| `TRAVELPAYOUTS_TOKEN` | Travelpayouts token |

### 4. გაშვება
**Actions → Check cheap flights → Run workflow.** პირველივე გაშვებაზე მოგივა მისასალმებელი შეტყობინება.
ამის შემდეგ ყველაფერი ავტომატურად მუშაობს ყოველ 6 საათში.

> თუ Actions გამორთულია, Actions ტაბზე დააჭირე „I understand… enable workflows“.

## 📱 პარამეტრების შეცვლა ტელეფონიდან

ბრძანებები იგზავნება თემაზე **`<შენი-თემა>-settings`** (მაგ. `luka-flights-8x3k29qz-settings`).

| ბრძანება | რას აკეთებს |
|---|---|
| `200` ან `ზღვარი 200` | ზღვარი: წასვლა+დაბრუნება ≤ 200₾ |
| `ღამე 3-7` | მოგზაურობის ხანგრძლივობა |
| `პირდაპირი` | მხოლოდ პირდაპირი ფრენები |
| `გადაჯდომა 1` | მაქსიმუმ 1 გადაჯდომა თითო მიმართულებაზე |
| `პაუზა` / `ჩართვა` | შეტყობინებების გაჩერება / ჩართვა |
| `სტატუსი` | მიმდინარე პარამეტრების ნახვა |

**როგორ გავაგზავნო:**
- **ღილაკებით:** „⚙️“ შეტყობინებებს აქვს ღილაკები `150₾` / `220₾` / `300₾`. ერთი შეხებით იცვლება ზღვარი.
- **ntfy ვებ-აპით:** Safari-ში გახსენი <https://ntfy.sh/app>, გამოიწერე `<შენი-თემა>-settings` და
  ჩაწერე ბრძანება (მაგ. `180`). შეგიძლია „Add to Home Screen“-ით აპივით დაიმატო.
- **iOS Shortcut-ით (ყველაზე მოსახერხებელი):** Shortcuts → ახალი →
  1. *Ask for Input* (Text, „ბრძანება?“)
  2. *Get Contents of URL*: `https://ntfy.sh/<შენი-თემა>-settings`, Method **POST**,
     Request Body **File** → *Provided Input*.

  დაარქვი „ფრენების ზღვარი“ და დაიმატე Home Screen-ზე.

ცვლილება ძალაში შედის **შემდეგ შემოწმებაზე** (მაქსიმუმ 6 საათში). დაუყოვნებლივ გასაშვებად GitHub აპში:
Actions → Run workflow. შეცვლის შემდეგ დამადასტურებელი „⚙️ პარამეტრები განახლდა“ შეტყობინება მოგივა.

საწყისი მნიშვნელობები ინახება `config.yaml`-ში, ბოლოს დაყენებული კი `state/state.json`-ში.

```
✈️ 170₾ · თბილისი → Milan → ქუთაისი
🛫 10 დეკ (ხუთ) TBS→BGY · Wizz Air · პირდაპირი · 93₾
🛬 15 დეკ (სამ) MXP→KUT · Pegasus · 1 გადაჯდომა · 77₾
🌙 5 ღამე · სულ 170₾ (≈55€)
```
- შეტყობინებაზე დაჭერა გახსნის **წასვლის** ბილეთის გვერდს.
- ღილაკი **↩️ დაბრუნება** გახსნის დაბრუნების ბილეთის გვერდს (როცა ეს ორი ცალკე ბილეთია).
- ფასი ერთი მგზავრისაა, **ბარგის გარეშე**. Aviasales-ის ფასები ბოლო 1–2 დღის ძიებებიდანაა, ამიტომ
  დაჯავშნამდე ყოველთვის გადაამოწმე.
- თუ რომელიმე წყარო 24 საათზე მეტხანს არ მუშაობს (მაგ. Wizz Air-მა დაბლოკა), „⚠️“ შეტყობინება მოგივა.
